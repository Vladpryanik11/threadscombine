# threadscombine

Личный ИИ-помощник для Threads — расширение Chrome (WXT, TypeScript, Preact). Только для владельца:
собственный ключ OpenRouter, данные в браузере, без сервера и входа.

Сейчас готова часть 1 «Ядро»: боковая панель, настройки, несколько аккаунтов, клиент OpenRouter с учётом
расходов, экспорт и импорт данных, журнал. Остальное — части 2–7 из [дорожной карты](docs/roadmap.md).

## Установка и запуск

Нужны Node 24 и npm.

```
npm install        # зависимости
npm run dev        # разработка: сборка с перезагрузкой при изменениях
npm run build      # сборка в .output/chrome-mv3
npm test           # тесты
npm run typecheck  # проверка типов
```

### Установка в Chrome

1. Выполните `npm run build`.
2. Откройте «Расширения» (`chrome://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `.output/chrome-mv3`.
4. Откройте Threads и нажмите на иконку расширения — откроется боковая панель.

## Ручная приёмка ядра

Проверяется в Chrome после каждой сборки:

1. `npm run build` → «Загрузить распакованное» из `.output/chrome-mv3` → расширение ставится без ошибок.
2. На открытом Threads клик по иконке открывает боковую панель.
3. Панель показывает тип страницы: «Лента», «Профиль @user», «Пост», «Поиск „запрос“» или
   «Откройте Threads»; при переходах внутри Threads (без перезагрузки) плашка обновляется
   в течение 1 секунды; при переключении вкладки браузера — тоже.
4. В настройках: ввести ключ OpenRouter, выбрать основную и запасные модели, нажать «Проверить» —
   приходит ответ модели со временем, токенами и стоимостью. С неверным ключом — сообщение
   «Неверный ключ OpenRouter».
5. Вкладки Аналитика · Контент · Комментарии · Клиенты · Чат открываются и показывают заглушку «Скоро».
6. Экспорт создаёт JSON-файл; импорт этого файла в режиме «заменить» восстанавливает настройки
   (кроме ключа, если галочка не стояла) и данные, включая аккаунты.
7. При первом запуске есть аккаунт «Основной». Можно создать второй аккаунт из переключателя в шапке,
   переключиться на него (выбор сохраняется после закрытия панели), привязать @username, удалить
   с подтверждением; удалить последний аккаунт нельзя.
8. После «Проверить» в разделе «Расходы» растёт сумма «Сегодня»; лимиты на день и месяц сохраняются.

## Правило: никакой автопубликации

ИИ готовит черновик и вставляет его в поле ответа; публикует человек одним нажатием. Расширение не нажимает
«Опубликовать» и не имитирует действия пользователя на Threads. Нет имитации «живого человека» для обхода
антиспама и нет массовых действий без подтверждения. Публикация через официальные API сторонних сервисов
(Postmypost) — только по явному действию владельца.
